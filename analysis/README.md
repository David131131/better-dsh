# Better DSH 实验结果

实验通过本机 DSH 调用 DeepSeek 官方 `deepseek-flash`。测试对象是 DSH 的调用与收尾策略。统计同时保留交付验收、自动收尾位置、API 中断、输出 tokens 和按固定费率估算的费用。

截至 2026 年 11 月 16 日，累计有 **531 条启动或续跑记录**，覆盖 **74 道独立任务**。其中 493 次计量完整，已观测 API 用量的固定价估算约为 **5.50 美元**。重复运行与诊断启动均计入运行总数。

| 对照 | 交付结果 | 匹配输出 tokens 变化 | 匹配估算费用变化 |
|---|---:|---:|---:|
| `low` 开启三项检查 | 12/12 → 12/12 | −32.4% | −32.1% |
| `high` 开启三项检查 | 11/12 → 12/12 | −38.4% | −35.9% |
| 固定 `low`，提示省略测试命令，开启三项检查 | 12/12 → 10/12 | −38.9% | −40.3% |
| 固定 `low`，从同一失败补丁开始，开启失败反馈 | 11/12 → 12/12 | −31.6% | −18.1% |

前两行来自同一批 6 道修订题。共有 11 个四组配对计量完整。第三行的两次交付失败分别来自 API 流中断和边界检查失败后未修复。第四行的真实 API 计量从加载失败补丁后开始，唯一的交付差异来自版本后缀题。排除该题后，开启反馈的费用增加 5.5%。

JavaScript 留出对照中，三项组有 1/8 份自动收尾补丁未通过隐藏验收。首版适用范围是明确指定文件与验收命令的 Git 项目。公开版提供实验方法和可复跑的基础用例。 [基础实验](../experiment-v0/README.md) · [计量口径](../experiment-v0/MEASUREMENT.md)
